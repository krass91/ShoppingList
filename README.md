# ShoppingList 🛒

Приложение за списък с продукти / списък за пазаруване за **Android** — Kotlin, Material Design 3, локална база данни.

> 📦 **Инсталационен файл:** [app-debug.apk](app-debug.apk) (~5.9 MB)

## 📱 Какво прави приложението

- ➕ **Добавяне на продукти** — удобен диалог с име, количество и категория
- 🍎 **Категории** — Храна 🍔, Напитки 🥤 и Друго 📦 (отделни икони за всяка)
- 📋 **Списък на продуктите** — картички (Material Cards) с възможност за изтриване
- 💾 **Запазва се локално** — данните не излизат от телефона, без акаунти и интернет регистрация

## 🛠 Технологии

| Компонент | Използвано |
|---|---|
| Език | Kotlin + Coroutines |
| База данни | Room (SQLite) |
| Интерфейс | Material Design 3 (Material You), CardView, RecyclerView |
| Android | minSdk по подразбиране (нови Android версии) |
| Build | Gradle 8.13.2 |

## ⬇️ Инсталация

1. Изтеглете [`app-debug.apk`](app-debug.apk) от това репо (бекон **Code → Download** или по име на файла).
2. Отворете файла на телефона.
3. Ако Android попита за позволено е „Инсталиране от неизвестни източници“ — разрешете за браузъра/файловия мениджър.
4. Инсталирайте и отворете приложението.

> ⚠️ Това е **debug (тестов) билд** — пакeт: `com.example.shoppinglist`.
